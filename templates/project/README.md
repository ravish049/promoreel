# {{NAME}} reels

A promoreel project. Edit these, then run `promoreel all <this folder>`:

- `brand.json`: colours, font, logo and photo (files in `public/`), the closing grid's features, and the outro's voice.
- `flows/*.flow.json`: what the recorder does in your app, one clip at a time (`docs/flows.md`).
- `reels/*.json`: the script and the scenes (`docs/spec.md`).

Renders land in `out/`, listed in `out/manifest.json`.
